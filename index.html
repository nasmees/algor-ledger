Features

  • CLI + GUI (F7) สไตล์ ERP ยุค midrange
  • สินค้า / สต็อก / ขาย / ซื้อ
  • ใบเสร็จ 80mm + พิมพ์อัตโนมัติ
  • รายงานรายวัน / เดือน / กำไรขั้นต้น
  • ไฟล์ .vault เข้ารหัส AES-256

Quick start

  • เปิด algor-ledger.html ใน Chrome/Edge
  • เลือกภาษา → MODE OWNER
  • SETPASS → SETNAME → ITEM ADD
  • SALE หรือกด F7 เข้า GUI
  • SAVE เพื่อได้ไฟล์ .vault

Design

UI ได้รับแรงบันดาลใจจาก IBM AS/400 / 5250 และจอ CRT ฟอสเฟอร์อำพัน ที่ใช้กับเครื่องบัญชีสมัยก่อน — อ่านตัวเลขได้นาน เบา และอยู่ภายใต้การควบคุมของคุณ
