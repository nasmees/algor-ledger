About

ALGOR LEDGER คือระบบบัญชีและสินค้าคงคลังแบบ local-first สำหรับร้านค้าและบริษัทเล็ก UI เป็นเทอร์มินัลยุค midrange / AS/400 โทน CRT amber — อ่านตัวเลขได้นาน เบา และอยู่ภายใต้การควบคุมของคุณ

ต่อยอดแนวคิด “คอมพิวเตอร์เล็ก ความจำใหญ่” ของ ALGOR Brain Vault แต่โฟกัสที่งานร้าน — สต็อก ขาย ซื้อ ใบเสร็จ รายงานรายวัน/เดือน และไฟล์ .vault ที่เข้ารหัสได้

“inventory · sales · receipts · real books · no cloud”

ทุกอย่างรันในเบราว์เซอร์ ข้อมูลไม่ออกจากเครื่องคุณ ดีกว่าต้องเช่า cloud สำหรับร้านเล็ก

ALGOR LEDGER is a local-first inventory and ledger for small shops and companies. The UI is a midrange / AS/400-style terminal in CRT amber phosphor — easy on the eyes, light, and under your control.

It continues the “small computer · big memory” idea of ALGOR Brain Vault, focused on shop work — stock, sales, purchases, receipts, day/month reports, and an encrypted .vault file.

“inventory · sales · receipts · real books · no cloud”

Everything runs in the browser. Data stays on your device — better than renting cloud for a small shop.

เริ่มใช้งาน

Quick start

  1. กด เปิด ALGOR LEDGER (หรือเปิด algor-ledger.html)
  2. Click Launch ALGOR LEDGER (or open algor-ledger.html)
  3. เลือกภาษา — 1 ไทย / 2 English
  4. Choose language — 1 Thai / 2 English
  5. พิมพ์ MODE OWNER แล้ว SETPASS · SETNAME
  6. Type MODE OWNER then SETPASS · SETNAME
  7. ITEM ADD ... แล้วลอง SALE หรือกด F7 เข้า GUI
  8. ITEM ADD ... then try SALE or press F7 for GUI
  9. พิมพ์ SAVE เพื่อได้ไฟล์ .vault เข้ารหัส
  10. Type SAVE to get an encrypted .vault file
  11. ครั้งถัดไป LOAD แล้วใส่รหัสผ่าน
  12. Next time LOAD and enter the password

ความปลอดภัย

Security

AES-256-GCM · PBKDF2 120k rounds · Web Crypto API

  • รหัสผ่านไม่ถูกเขียนลงดิสก์ — ต้องใส่ทุกครั้งที่ LOAD
  • ลืมรหัสผ่าน = กู้ไฟล์ .vault ไม่ได้
  • LOCK ล้างรหัสออกจากหน่วยความจำเมื่อเดินจากเครื่อง
  • SAVERO สร้างไฟล์ที่เปิดได้แค่โหมดดู
  • รันออฟไลน์ได้หลังโหลดหน้า (ฟอนต์อาจต้องเน็ตครั้งแรก)
  • Password is never written to disk — required on every LOAD
  • Lost password = .vault cannot be recovered
  • LOCK clears the password from memory when you step away
  • SAVERO creates a read-only vault file
  • Works offline after load (fonts may need network on first visit)
